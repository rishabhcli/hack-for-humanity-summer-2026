## Devpost submission form — exact fields

These are the literal fields on the draft submission wizard, read from the live form.

### Step 1 — Project overview
- `Project name` — required, **60 character limit**
- `Elevator pitch` — required, **200 character limit**
- `Thumbnail` — JPG / PNG / GIF, 5 MB max, 3:2 ratio recommended

### Step 2 — Project details
- `* About the project`
- `* Built with`
- `"Try it out" links`
- `Image gallery`
- `Choose files`
- `* Video demo link`

Field notes:
- `About the project` — Markdown with LaTeX support. Devpost's own placeholder prompts for **Inspiration / What it does / How we built it / Challenges / Accomplishments / What we learned / What's next**.
- `Built with` — tag list, **max 25 tags** (languages, frameworks, platforms, cloud services, databases, APIs).
- `Try it out links` — repeatable URL field for demo site, app store listing, or GitHub repo.
- `Image gallery` — JPG / PNG / GIF, 5 MB max each, **up to 15 images**, 3:2 ratio recommended.
- `Video demo link` — must be a **YouTube, Facebook Video, Vimeo or Youku** URL. Embedded at the top of the project page.

## What to build / Requirements

What to Build

You must build software (such as an app, website, or game) that improves mental or physical well-being. In addition to the core Mental Health and Physical Health categories, your project can compete in several dedicated tracks:

- Best Use of AI/ML & Responsible AI: For projects implementing machine learning.

- Best Tech for Concussion Recovery: For projects addressing brain injury recovery

- Additional prizes for Best Design (Presented by Better Design), Girls Who Code Future Innovator Award, Best Use of Render, Best Innovation and Creativity, and the Public Voting Winner.

What to Submit

- Software: Include the GitHub repository for your software with the functioning source code.

- Video: A video (4 min max) explaining

- The issue you're solving

- Your submitted software and its functionality in detail

- An overview of how it was created
